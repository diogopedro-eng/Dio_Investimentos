# DiogoInvest

Planilha de simulação de investimentos desenvolvida no Excel para
explorar a evolução do patrimônio e estimar renda passiva com base
em aportes mensais, prazo e taxas de rendimento.

## Funcionalidades

- Configuração de salário, aporte mensal e taxas de retorno.
- Projeção de patrimônio acumulado e dividendos mensais.
- Comparação de cenários para diferentes prazos de investimento.
- Distribuição de aportes entre categorias de Fundos de Investimento
  Imobiliário (FIIs).
- Alocações sugeridas para os perfis Conservador, Moderado e Agressivo.

## Estrutura da planilha

- **DiogoInvest:** configurações, simulações e distribuição dos aportes.
- **FII:** percentuais de referência por categoria e perfil de investidor.

## Como usar

1. Abra a planilha no Excel.
2. Ajuste os valores de aporte, prazo e taxas de rendimento.
3. Selecione o perfil de investimento.
4. Consulte as projeções e a distribuição dos valores por categoria.

## Aviso

As projeções são simulações e não garantem rentabilidade futura.
Os percentuais apresentados não constituem recomendação de investimento.
